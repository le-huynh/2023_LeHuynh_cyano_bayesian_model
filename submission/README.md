# Manuscript files

This folder contains the manuscript source files and related materials used to 
generate the final document in multiple formats.

## Structure

- `manuscript.Rmd`  
  Main executable R Markdown document for the study.

- `manuscript.tex`  
  LaTeX version generated from the R Markdown file.

- `manuscript.pdf`  
  PDF version of the manuscript.

- `manuscript.docx`  
  Microsoft Word version of the manuscript.

- `my_header.tex`  
  Custom LaTeX header file used for formatting the PDF manuscript.

- `bibliography.bib`  
  BibTeX-formatted reference library.

- `XXXX.csl`  
  Citation Style Language (CSL) file used to format references according to the 
  target journal style.

- `*.Rmd`  
  Child R Markdown documents included in the main manuscript.
